# Relatório de Orçamento de Viagem: Curitiba - São Paulo - Santos - Araras

Este relatório detalha os custos estimados para uma viagem de 5 dias para duas pessoas, saindo de Curitiba para São Paulo (voo), seguindo para Santos e Araras de carro, com hospedagem em **quartos separados** (2 quartos) e alimentação.

## 1. Voos (Curitiba - São Paulo - Curitiba)

Com base na pesquisa no Google Flights para agosto de 2026, os preços de voos de ida e volta de Curitiba (CWB) para São Paulo (CGH/GRU) para uma pessoa variam. Os valores mais baixos encontrados foram:

*   **LATAM (CWB-CGH):** SAR 338 (aproximadamente R$ 456,30) [1]
*   **Azul (CWB-CGH):** SAR 338 (aproximadamente R$ 456,30) [1]
*   **Gol (CWB-CGH):** SAR 373 (aproximadamente R$ 503,55) [1]

Considerando o valor mais baixo para duas pessoas (ida e volta):

*   **Custo Estimado de Voos:** 2 x R$ 456,30 = **R$ 912,60**

## 2. Aluguel de Carro e Custos de Deslocamento (São Paulo - Santos - Araras - São Paulo)

Para o aluguel de carro por 5 dias em São Paulo, um carro econômico pode ter um custo médio de R$ 134/dia [2], totalizando:

*   **Custo Estimado de Aluguel de Carro (5 dias):** 5 x R$ 134 = **R$ 670,00**

Os custos estimados de combustível e pedágios para a rota São Paulo - Santos - Araras - São Paulo foram calculados da seguinte forma:

*   **Combustível:** R$ 251,13
*   **Pedágios:** R$ 138,70
*   **Total Carro (Combustível + Pedágios):** **R$ 389,83**
